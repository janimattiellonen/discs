# Disc Golf Application

This project uses [Vite](https://vitejs.dev/) as the build tool and development server, with [Redux](https://redux.js.org/) and [Redux Toolkit](https://redux-toolkit.js.org/) for state management.

The project was migrated from Create React App to Vite for improved development experience and faster build times.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode using Vite.\
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

The page will reload when you make changes with hot module replacement (HMR).

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `dist` folder using Vite.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include hashes for cache busting.

### `npm run preview`

Locally preview the production build. Run `npm run build` first to generate the production build, then use this command to preview it at [http://localhost:4173](http://localhost:4173).
